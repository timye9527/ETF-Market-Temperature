## 1. 温度：相对自身趋势的偏离

### 1.1 为什么不直接用“价格的 5 年百分位”
一只稳定上涨的资产，价格、离均线的距离都会越来越大，按价格算的百分位会一直显示“极热”，可它只是趋势健康。这与“过热 → 减仓”的用法矛盾（Owner 指出）。

### 1.2 做法：先找到趋势，再看偏离
- **趋势线**：对数价格在过去 126 日和 252 日上的滚动线性回归（两条，对应 6 个月与 1 年）。稳定上涨的资产，价格贴着自己的回归线走。
- **偏离**：今天的对数价格 − 回归线上的值，再除以回归残差的标准差 → **偏离 z 值**。贴着趋势走 ≈ 0；脱离趋势加速上冲 → 正得很大；跌穿趋势 → 负得很大。
- **温度** = 综合热度在自身过去 5 年中的百分位（≥1 年历史即可开始，< 5 年标注置信度）。由此：
  - 稳定的强趋势：趋势状态 = 强上升，温度 ≈ 中性；
  - 加速冲顶：温度 → 极热；
  - 恐慌下跌、跌穿趋势：温度 → 极冷。

### 1.3 区间（按定义，每个区间的历史频率固定）
| 温度 | 区间 | 含义 |
|---|---|---|
| 95–100 | 极热 | 比自身过去 5 年 95% 的日子都热 |
| 80–95 | 热 | |
| 60–80 | 偏暖 | |
| 40–60 | 中性 | |
| 20–40 | 偏冷 | |
| 5–20 | 冷 | |
| 0–5 | 极冷 | 比自身过去 5 年 95% 的日子都冷 |

### 1.4 五个维度（权重先用提议值）
每个子指标先变成自身 5 年百分位（0–100），维度 = 子指标均值，综合热度 = 维度加权平均，温度 = 综合热度的 5 年百分位，再取 3 日平均。

| 维度 | 权重 | 子指标 | 说明 |
|---|---|---|---|
| A 偏离趋势 | 30% | 126 日与 252 日回归偏离 z；周线 RSI(14) | 核心：离自己的趋势有多远 |
| B 动量加速 | 20% | 20 日、60 日收益减去趋势应有的涨幅（以波动率为单位） | 涨得比趋势快 = 加速 |
| C 拥挤度 | 20% | 带方向的成交额（20 日成交额 / 1 年中位数，按涨跌定方向）；杠杆情绪（§1.6） | 资金是否挤进来/逃光 |
| D 广度 | 15% | 子板块 ETF 与所属大市值个股中，站上 50 日线比例、20 日新高 − 新低 | 普涨还是少数撑着 |
| E 相对强弱偏离 | 15% | 相对上级节点的比价，同样做回归偏离 z | 资金是否异常集中于此 |

另保留 V1 温度作为**短期温度**（252 日窗口、偏短线），只作副读数。

### 1.5 趋势状态（与温度并列）
252 日回归的年化斜率与 R²：
| 状态 | 条件 |
|---|---|
| 强上升 | 年化 > +20% 且 R² > 0.5 |
| 上升 | 年化 > +5% |
| 震荡 | 其余 |
| 下降 | 年化 < −5% |
| 强下降 | 年化 < −20% 且 R² > 0.5 |

页面用“趋势 × 温度”四象限展示：强趋势 + 中性温度 = 健康；强趋势 + 极热 = 过热；下降 + 极冷 = 超卖；下降 + 温度不冷 = 阴跌（价值陷阱警示）。

### 1.6 杠杆块（单独一块）
所有杠杆与反向 ETF（指数类和单股类）都归入“杠杆情绪”，按其标的映射到节点：
- 指数/行业杠杆：如 SOXL/SOXS → 半导体；
- 单股杠杆：如 NVDL → NVDA → 半导体；MUU → MU → 存储。

同一节点内，指数杠杆与单股杠杆分别算 Bull Share、多头活跃、空头活跃，再平均；页面单独展示这一块。正股本身只按行业归属进入广度与映射，不进入杠杆块。杠杆成员必须通过自动校验（对标的日收益回归，β 在目标倍数 ±15% 内且 R² ≥ 0.85）。

### 1.7 极端确认清单
进入极热/极冷时，逐条检查，满足 ≥ 3 条且持续 ≥ 3 个交易日才标记“确认”：

| 极热 | 极冷 |
|---|---|
| 252 日偏离 z ≥ 自身 5 年 95 分位 | ≤ 5 分位 |
| 周线 RSI > 70 | < 30 |
| 动量加速 ≥ 90 分位 | ≤ 10 分位 |
| 带方向成交额 ≥ 90 分位 | ≤ 10 分位 |
| 杠杆情绪 ≥ 90 分位 | ≤ 10 分位 |
| 广度：站上 50 日线 ≥ 85% | ≤ 15% |

### 1.8 短历史 ETF 的回填
DRAM、EUV 等上市不足 1 年：用持仓前几大股票按权重合成一条价格，回填上市前历史，页面标注“合成回填”。

## 2. 周期资格（自动检验 + Owner 复核）

| 类别 | 冷 → 布局 | 热 → 减仓 |
|---|---|---|
| 周期型 | 是 | 是 |
| 结构成长 | 是（分批） | 只提示“不追高” |
| 防御型 | 温度仅参考 | 同左 |
| 结构衰退 | 否（价值陷阱） | 是 |
| 工具型 | 不适用 | 不适用 |
| 宏观资产 | 单独解释 | 单独解释 |

自动检验（对节点价格，含回填）：
- T1 长期价值：10 年（不足则全部历史）年化总回报 > 0。
- T2 有周期：至少 2 次 ≥ 20% 回撤并在 3 年内收复前高。
- T3 冷热有效：该节点自身历史上，进入“冷”（< 20）之后 120 日收益中位数 > 进入“热”（> 80）之后，每侧独立事件 ≥ 3 次。
- T4 结构性跑输：相对上级节点的比价 5 年回归斜率 < −10%/年，**且**绝对年化回报 < 3%（低于现金）。只跑输指数不算价值毁灭（D-033）。
- T5 工具型：期货展期策略、波动率 ETP。

自动建议写入数据；Owner 在 `data/eligibility.yaml` 填写最终类别与原因，人工结论优先。复核前，页面标注“自动建议，待复核”。

| 映射 | 用途 |

## 4. 广度
不做全量成分股。每个节点的广度样本 =
- 子节点 ETF（每个子节点 1 票），加上
- 映射到该节点子树的大市值个股（约 50 只美股最大市值 + 存储链少数海外股）。

样本 < 5 时不计算广度。另提供“集中度”读数：S&P 500 等权（RSP）相对市值加权（SPY）的偏离。

## 5. Universe：按流动性 Top 20
- ETF 候选池：`data/etf_universe.yaml`，每只 ETF 标注类别（bucket）。
- 每天按 60 日成交额中位数在类别内排名，取 **Top 20**。
- 覆盖保证：每个节点至少保留其流动性最好的核心 ETF（成交额 ≥ 1000 万美元），否则节点显示“无覆盖”。
- 配对补全：选中某只杠杆 ETF 时，同 Family 另一方向的成员一并纳入，避免单边。
- 类别：美股宽基与风格、美股行业（GICS 11）、美股细分行业、主题、指数杠杆/反向、单股杠杆/反向、债券、商品与贵金属、国际（美股上市）、加密、参照（VIX、美元、短债）。
- 港股本地 ETF：下一版之后。

## 6. 参考动作（只在节点详情页）
| 确认后的温度 | 周期型 | 结构成长 |
|---|---|---|
| 极热 | 参考减仓 | 不追高 |
| 热 | 不新增 | 不追高 |
| 偏暖 / 中性 / 偏冷 | 观望 | 观望 |
| 冷 | 开始分批 | 开始分批 |
| 极冷，且动量加速 ≤ 10 分位（仍在加速下跌） | 等待企稳 | 等待企稳 |
| 极冷，下跌减速 | 加大分批 | 分批 |

旁边显示该节点自身历史：进入当前区间的次数，之后 60/120 日收益中位数与最差值。独立事件 < 3 次时不显示动作。参考动作是历史描述，不是投资建议。
